🍷 Wine Dataset Analysis using Machine Learning
📌 Project Overview

This project explores the Wine dataset using Machine Learning techniques to perform classification, clustering, and dimensionality reduction. It compares supervised and unsupervised learning approaches and 
presents insights through an interactive dashboard.

🛠 Technologies Used
Python
Pandas, NumPy
Scikit-learn
Matplotlib
Streamlit

Git & GitHub
🔍 Features & Workflow
Data preprocessing using StandardScaler
Logistic Regression for supervised classification
K-Means Clustering with Elbow Method
PCA (Principal Component Analysis) for dimensionality reduction and visualization
Interactive Streamlit dashboard for visual insights

📊 Models & Techniques
Logistic Regression
K-Means Clustering
Elbow Method
PCA

📈 Evaluation Metrics
Classification Accuracy
Adjusted Rand Index (ARI)
Silhouette Score

🚀 How to Run the Project
1️⃣ Clone the repository
